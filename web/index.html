SupaWallet

Every GitHub user already has a Solana wallet. Pay anyone by GitHub username; they spend with stock ssh-keygen and the SSH key on their profile. Solana devnet.

1. Find a GitHub user's wallet

2. Pay them

Uses Phantom (or any Solana wallet extension) set to devnet. The SOL lands in their vault, even if they've never heard of SupaWallet.

3. Spend from your vault with your SSH key

Look yourself up in step 1 first. Your ed25519 key must be synced on-chain (supawallet sync). Your wallet extension only pays the transaction fee as the relayer; the money moves because your SSH key signed the text below.


      
      
      
ssh-keygen -Y sign -n supawallet@v1 -O hashalg=sha256 -f ~/.ssh/id_ed25519 intent.txt
